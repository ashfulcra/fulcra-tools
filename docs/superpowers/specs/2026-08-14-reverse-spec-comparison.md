# System specification and implementation design

The public [`SYSTEM-SPEC.md`](../../coord/SYSTEM-SPEC.md) introduces the architecture
and shipped behavior. The [`implementation design`](2026-08-14-collect-coord-bus-rebuild-design.md)
and [`implementation plan`](../plans/2026-08-14-collect-coord-bus-rebuild.md) describe
component boundaries, invariants, and verification tasks.

Read the system specification first, then use the design and plan for implementation.
Keep private agent comparisons, source-account evidence, and execution history in the
team's own storage. Public revisions should preserve technical rationale and reference
reproducible, synthetic examples.
